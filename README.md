#  Marathi Wedding Invitation Website

A beautiful and modern wedding invitation website built using React and Tailwind CSS. This project is designed to create a memorable digital invitation experience with elegant UI, animations, and music.

---

##  Features

- 🎨 Responsive and modern design  
- 🎬 Smooth animations using Framer Motion  
- 🎵 Background music for better experience  
- 💌 Wedding details and event sections  
- 📱 Mobile-friendly layout
